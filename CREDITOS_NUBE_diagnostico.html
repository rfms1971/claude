Los otros tres «créditos», que no sirven acá

  • Créditos de API del Console (pay-as-you-go) — no se gastan mientras estés logueado con la suscripción.
  • Créditos de API mensuales del plan Max — textual: «can't be used in Claude Code or the Claude apps, including for extra usage».
  • Usage credits / extra usage — sí funcionan en Claude Code, pero son otra cosa: se habilitan en Settings → Usage, se facturan aparte a tarifa API, y entran después de que el bono se agote.

Lo que esto explica del protocolo

Contradicción sin resolver

LEIDOLa documentación de Claude Code afirma que «Routines: scheduled and triggered runs each run as a cloud session». El artículo de soporte excluye Routines del bono. Las dos son fuentes oficiales y se contradicen; no lo resolví. Posible lectura: una Routine es técnicamente una sesión de nube pero queda excluida de la promoción a propósito.

La medición que lo decide

De solo lectura, y discrimina entre las dos hipótesis:

  • Anotar el saldo exacto ahora.
  • Dejar correr una Routine.
  • Volver a mirar el saldo.

Si bajó → las Routines sí consumen el bono, y el corte del 10-02 tuvo otra causa.
Si quedó igual → confirmado: las Routines van contra el plan. Ahí está la causa, y el arreglo es migrar el informe a una sesión de nube disparada a mano mientras dure el crédito.
